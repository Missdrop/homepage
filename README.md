# Missdrop · Homepage

My personal homepage, built with vanilla HTML, CSS, and JavaScript and customized from the original project.

A simple static site with no frontend framework, package dependencies, or build step.

## Tech Stack

- **HTML** — Page structure and content
- **CSS** — Responsive layouts, themes, and visual effects
- **JavaScript** — Theme switching and page interactions

## Project Structure

```text
index.html         Page entry point
static/css/        Styles and theme variables
static/js/         Interaction logic
static/svg/        SVG icons
static/img/        Image assets
static/fonts/      Font files
```
